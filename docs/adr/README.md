# Switchyard Initial Architecture Decision Records

These ADRs were ratified by the Part 7 pre-v0.1 implementation gate on 15 September 2026.

They consolidate the 30 candidate ADR topics produced by Parts 2-6 into ten high-value decisions.

| ADR | Decision |
|---|---|
| ADR-0001 | Architecture boundaries and runtime model |
| ADR-0002 | Distributed consistency and reliable messaging |
| ADR-0003 | Order placement orchestration and financial sequencing |
| ADR-0004 | Identity, sessions and authorization |
| ADR-0005 | Public demo safety and privileged controls |
| ADR-0006 | Observability and diagnostics model |
| ADR-0007 | Testing and quality gates |
| ADR-0008 | Persistence topology and migrations |
| ADR-0009 | Messaging transport and broker security |
| ADR-0010 | Azure runtime, IaC, delivery and cost |

Future ADRs should be added only for decisions that are architecturally significant, difficult to reverse or important to explain publicly.
